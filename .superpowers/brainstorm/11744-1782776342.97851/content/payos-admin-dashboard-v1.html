MiLingo Admin - Payment detection and metrics dashboard

Màn này show luồng PayOS hiện tại và 3 hướng lấy dữ liệu cho dashboard doanh thu, user, giao dịch, review.

PayOS detect hiện tại

1. User chọn gói Mobile gọi backend tạo PayOS order. Backend lưu `payment_orders` status `PENDING`.
2. PayOS checkout User thanh toán trên PayOS bằng link checkout.
3. Webhook về BE PayOS gọi `api/v1/payments/payos/webhook` khi có trạng thái thanh toán.
4. BE verify Backend check HMAC signature, check amount, rồi set `status = PAID`.
5. Admin đọc số liệu Dashboard tổng hợp từ `payment_orders`, `users`, và collection review.

Chọn hướng lấy dữ liệu dashboard

A. Admin đọc Firestore trực tiếp

Nhanh, ít code backend. Nhưng rules dễ lộ dữ liệu nếu admin role chưa chặt.

B. Backend Admin API

Đề xuất. Backend tổng hợp số liệu, admin chỉ gọi 1 endpoint. Dễ bảo vệ bằng Firebase custom claim `admin`.

C. Hybrid

Dashboard summary từ backend, bảng gần realtime từ Firestore. Linh hoạt nhưng nhiều logic hơn.
